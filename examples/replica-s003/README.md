# 复刻案例：对话气泡 + 旋转拉远（ref.mp4 · s003）

9.1 秒 / 273 帧。插画开场是一个斜着的特写，旋转拉远回到全景，三个对话气泡依次落下、升起、飞走，中途镜头再推近一点。

**只复刻画面。** 原片底部那行口播字幕是后期加的，不在模板里，比对时用 `--mask` 遮掉。

## 怎么用（不用敲命令）

1. 在访达里打开这个文件夹，**双击 `打开模板.command`**（第一次会装依赖，1–3 分钟）
2. 浏览器自动打开预览页面。点右上角的面板按钮，右侧出现所有参数
3. 改完画面立刻更新，**而且会自动存回代码**，下次打开还在
4. 满意了点右下角 **Render** 导出视频

| 想改什么 | 改哪里 |
| --- | --- |
| 换成你的插画 | 把图片放进这个文件夹的 `public/`，在 `image` 一栏填文件名。图越清楚越好，开场会放大 3 倍 |
| 气泡说的话 | `bubbles` 里每一项的 `text`；要标黄的字填进 `highlight` |
| 气泡什么时候出现、飞走 | `enter` / `exit` 的 `start`、`end`（帧号，30 帧 = 1 秒） |
| 开场放大多少、斜多少 | `camera` 的 `startScale`、`startRotation` |
| 开场特写对准哪里 | `camera` 的 `focusX`、`focusY`（原片是正中间 640, 360） |
| 推近多少 | `camera` 的 `endScale` |
| 气泡颜色、圆角、字号、投影 | `bubbleStyle` |

大一点的改动（比如「气泡改成从左边滑进来」），直接用一句话告诉 AI，让它改 `src/DialogueShot.tsx`。

> 第一次点 Render 时，Remotion 会从 remotion.media 下载一个渲染用的浏览器（约 100MB），网络不通会失败，重试或换个网络即可。

## 结果

| | 平均 SSIM | 最低单帧 | 逐帧平均误差 |
| --- | ---: | ---: | ---: |
| 第一版 | 0.9698 | 0.9422 | 3.29 |
| **最终** | **0.9767** | **0.9544** | **2.64** |

口播字幕区（300, 605, 680×100）不计。误差 = 逐帧平均绝对误差（0–255）。

分阶段看（只看最终版）：

| 阶段 | 误差 | 说明 |
| --- | ---: | --- |
| 没有气泡的画面 | 1.2–1.5 | 镜头运动和底图基本吻合 |
| 气泡停留时 | 1.9–2.9 | 主要是**字体不同**：原片可能是苹方，这里渲染用的是思源黑体，笔画天然错位。按肉眼对过，不再追像素 |
| 开场拉远（第 11–45 帧） | 1.6 → 4.0 | 原片自己的瑕疵：人物剪影和背景条纹之间有 ≤0.8° 的相对漂移。模板不复刻这个瑕疵 |

比对报告会提示「画面中央越往后越不像」。这不是漏了动效：中央在后半段才出现气泡，而气泡文字字体不同。
中央没有气泡的帧误差 1.8，有气泡的帧 7.2。

## 这个镜头是什么（全部逐帧实测）

**镜头**：始终绕画面中心缩放 + 旋转，不平移。

| | 实测 | 怎么测的 |
| --- | --- | --- |
| 开场 | 放大 3.23 倍、顺时针斜 29.9°，定格约 12 帧 | 每帧和底图做相似变换配准，残差约 1 个灰度 |
| 拉远 | 缩放、旋转各自沿 cubic-bezier ≈ (1, 0, 0, 1) 回到 1 倍 / 0°，约第 97 帧到位 | 对 89 个清晰帧拟合贝塞尔，残差 0.2% |
| 推近 | 第 148–201 帧推到 1.198 倍，同一种缓动 | 同上 |
| 运动模糊 | 快门 0.27 帧 | 量气泡上沿的模糊宽度 ÷ 每帧位移，四处测得 0.26–0.28 |

**气泡**：在「世界层」里，跟着镜头一起缩放。

| | 入场 | 离场 |
| --- | --- | --- |
| 气泡 1 | 第 44–101 帧，从上方 120px 落下，同时淡入、由虚变实 | 第 145–173 帧，加速上飞 |
| 气泡 2 | 第 179–205 帧，从画面下方外 377px 升起，减速到几乎停住 | 紧接着第 204–220 帧加速上飞 |
| 气泡 3 | 第 233–269 帧，从下方 325px 升起 | 不离场 |

样式：深色圆角框（圆角 22，高 82），底色是**横向渐变**（中间灰度 ≈33，左 19、右 23），
1px 浅色描边，投影偏向**左下**（偏移 −28, 34，σ=13，不透明度 0.39），高亮字 `#d8b45a`。

**底图**：验证时用的是从原片反推的两张图（不在仓库里，见下文）。模板默认用一张自己画的示例图 `sample.jpg`。

## 迭代过程

**第 1 轮**：SSIM 0.970，误差 3.29。镜头运动基本对上，但气泡停留时误差翻倍。

**第 2 轮：气泡本体**。看着是纯黑的底色，逐列一量，中间比两边亮 14 个灰度，是横向渐变。
投影也不是正下方，而是偏左下。3.29 → 2.83。

**第 3 轮：发虚 ≠ 变淡**。追踪显示气泡飞走时透明度从 1 掉到 0.5，照做后渲染出来像幽灵。
回头看原片，气泡飞走时一直是实的，只是有运动模糊。模板匹配把模糊算成了透明。
改成不透明 + 运动模糊（先量出快门 0.27）。2.83 → 2.64。

**顺带发现**：气泡 2、3 其实是从画面**下方外面**升上来的，但前几帧正好藏在口播字幕区里，
追踪时被遮掉了，测出来的起点偏晚。逐帧肉眼补测了这几帧。

## 新踩的四个坑

（前四个见 [replica-s002](../replica-s002/)。这四个已经写进复刻包给 AI 的指令里。）

5. **发虚不一定是变淡。** 快速移动的元素带运动模糊，模板匹配会把模糊算成透明度下降。先量快门，扣掉模糊再判断。
6. **被口播字幕挡住的那几帧要单独看。** 遮掉字幕区之后，从底部升上来的元素前几帧就看不见了，入场起点会被测晚。
7. **从特写拉远的镜头，底图要够清楚。** 开场放大 3 倍，拿正常画面放大当底图会糊。用开场定格的 12 帧反推了一张 3.25 倍分辨率的特写底图。
8. **看起来是纯色的，逐列量一下。** 气泡底色的渐变肉眼看不出，像素误差看得出。

## 复刻验证（开发用）

需要原片片段和从它反推的两张底图，都不在仓库里（仓库是公开的，这些是别人的内容）：

- `clip.mp4`：ShotPilot 导出的复刻包里就有
- `public/plate.jpg`：常态底图，只用静止帧拼成（1.2 倍分辨率），挖掉气泡和字幕
- `public/plate-zoom.jpg`：开场特写底图，用开头定格的 12 帧拼成（3.25 倍分辨率）

两张底图的做法：逐帧配准出镜头参数，把每帧反变换回底图坐标，挖掉气泡和字幕后取平均。

```bash
pnpm install
pnpm render:replica          # 用 replica-props.json（原片精确测量值 + 反推底图）渲染 out.mp4
cd ../.. && pnpm compare --rendered examples/replica-s003/out.mp4 --original examples/replica-s003/clip.mp4 \
  --fps 30 --mask 300,605,680,100 --diff diff.mp4
```
