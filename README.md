# ShotPilot 拉片工作台

把别人视频里你喜欢的镜头，变成你自己能反复用的模板。

```
刷到一条喜欢的视频
   ↓  拉片：切成一个个镜头，标出哪些是 B-roll
挑出你喜欢的那个镜头
   ↓  导出复刻包，交给 AI
AI 把这个镜头做成模板，和原片逐帧比对到一样
   ↓  用模板做视频：换成你的图、你的文字
得到你自己的视频片段，画面效果和原片一样
```

**只管画面。** 镜头怎么切、构图、景别、运镜、元素摆在哪、动效怎么走。
声音（背景音乐、人声）和口播字幕不归这个工具管，那些在后期里加。

## 为什么不是又一个剪辑软件

剪辑软件是为「产出成片」设计的，拉片是为「理解别人怎么拍」设计的，两者需求相反：

| 拉片真正需要的 | 剪辑软件的做法 |
| --- | --- |
| 一次性看到全部分镜 | 时间轴要来回拖 |
| 每个镜头挂结构化标注 | 只能改文件名或加马克点 |
| 标注能导出、能交给 AI | 锁在工程文件里 |
| 分镜边界可反复调整而不丢标注 | 重切等于重来 |

## 安装（Apple 芯片的 Mac）

1. 下载 [`ShotPilot.dmg`](https://github.com/miaoeliauk-sketch/shotpilot/releases/tag/mac-latest)，双击打开，把 ShotPilot 拖进「应用程序」
2. **第一次打开**：在「应用程序」里右键点 ShotPilot →「打开」→ 再点「打开」。
   如果没有「打开」按钮：先双击一次，再去「系统设置 → 隐私与安全性」，往下找到 ShotPilot，点「仍要打开」。
   （软件没有花钱做苹果签名，所以 Mac 会多问这一次，以后直接双击就行）
3. 问「是否允许访问文稿文件夹」时点「允许」：你的项目和导出的视频都存在那里

软件里自带了需要的一切（ffmpeg、下载工具、导出视频用的组件），不用装别的，也不用开终端。
**更新**：下载新的 `ShotPilot.dmg`，拖进「应用程序」替换旧的。你的作品在「文稿」里，不受影响。

你的东西都在 **「文稿 / ShotPilot」**：

| 文件夹 | 里面是什么 |
| --- | --- |
| 拉片项目 | 每条拉过的视频的分镜和标注 |
| 下载的视频 | 从链接下载下来的原视频 |
| 复刻包 | 导出给 AI 的复刻包 |
| 我的作品 | 用模板做的视频的参数（改到哪一步都自动存着） |
| 素材 | 你换进模板的图片 |
| 导出的视频 | 用模板导出的成片 |
| B-roll 素材 | 放进 Eagle 的 B-roll 小片段（Eagle 会拷一份进自己的素材库） |

## 日常使用

窗口和剪辑软件一样分四块：左边一条是「拉片 / 模板 / 作品」，中间看画面，右边改参数，底下是时间轴。
左下角「文件夹」直接在访达里打开「文稿 / ShotPilot」。

**拉片**

- 右上角「新建拉片」：**粘抖音 / B 站链接**（整段分享文案也行），或者**直接把视频文件拖进窗口**，自动切分镜。
  抖音要求登录信息时，会自动借用 Chrome / Safari 的 cookie 重试（第一次会弹窗问你要不要允许读取，点允许）
- 底下时间轴上一块就是一个镜头，宽窄就是长短，颜色是归类。点一块看它，右边标归类、景别、运镜、构图、备注
- **导出复刻包**：右上角「导出复刻包」导出所有 B-roll / 叠加层 / 字卡；右边「导出这个镜头的复刻包」只导出选中的镜头。
  导出完自动在访达里打开文件夹，文件夹名是「视频名-镜头号」
- 右上角「…」里还有重新切分、AI 初判、导出拉片笔记和数据

**用模板做视频**

1. 左边点「模板」，选一个（鼠标移上去会播放；都是从别人视频里一帧一帧复刻出来的效果），点「用这个模板做视频」
2. 中间是实时预览。右边改选中的那部分：换底图（点「换一张图」或者直接把图片拖进去）、改气泡里的字、选从哪进来……
3. 底下时间轴上**拖色块改出现时间，拖两头改停多久**，点哪块右边就换成哪块的参数。所有改动自动保存
4. 右上角「导出视频」，导完自动在访达里打开

做过的都在左边「作品」里，改到一半的也在。

**B-roll 素材库（放进 Eagle）**

1. 第一次用：左下角「设置」→「看图 AI」选一家（通义千问、豆包、OpenAI…），填 API Key，点「保存并测试」
2. 拉片时把镜头标成 B-roll，右边会多一页「素材标签」。点「AI 打标」，AI 看画面按打标模板填：
   画面类型、场景倾向、基调、可用途（建议）、子场景、一句话描述、备注、把握度。填得不对直接改
3. 关系、身份（是不是本人）、具体事件 AI 一律不猜，都是「待人工确认」，你确认了再选
4. 打开 Eagle，点「放进 Eagle」。在 Eagle 的「ShotPilot 素材库 / 视频名」文件夹里：
   名称是「日期_场景大类-子场景_一句话描述_序号」（日期是拉片那天），标签是各项结果，注释是整段打标结果
5. 标签改了再点一次是更新那一条，不会多一份；你在 Eagle 里自己加的标签不会被动

一次处理整条视频：右上角「…」里有「AI 给还没打标的 B-roll 打标」和「把打过标的 B-roll 都放进 Eagle」。
Eagle 标签里带「待人工确认」的就是还有信息没确认的，在 Eagle 里按这个标签一筛就出来。

## 从源码运行（开发用）

```bash
git clone https://github.com/miaoeliauk-sketch/shotpilot.git ~/shotpilot
cd ~/shotpilot && pnpm install
brew install yt-dlp        # 用来下载链接里的视频
pnpm dev                   # 或者双击 ShotPilot.command
```

`ShotPilot.command` 会尝试更新（连不上 GitHub 时用「下载」里的 `shotpilot-update.bundle`）→ 依赖有变化才重装 → 打开浏览器。
从源码运行时数据放在项目目录下（`projects/`、`downloads/`、`replica-out/`、`works/`…）。

## 命令行（可选）

也可以不开网页，直接走命令行：

```bash
pnpm analyze --input /path/to/ref.mp4 --threshold 0.3
pnpm analyze --project <项目id> --export md --out 笔记.md
```

## 拉片

### 切分镜：三层兜底

自动检测不可能百分之百准，所以分三层：

1. **全局自动切**：ffmpeg `scene` 滤镜 + 最短镜头合并，一进来就跑，解决大部分
2. **单镜头细切**：时间轴上的「细切这个镜头…」，只对选中的镜头调高灵敏度重测
3. **手动补刀**：播到画面变了的地方按 `S`（切的是播放头下面那个镜头）；切多了按 `M` 并回上一个

为什么需要后两层：同一条片子里不同内容的场景分数差一个数量级。真人画面人一动整帧都在变，分数很高；
录屏演示只有鼠标和局部界面在变，占整帧不到 5%，分数被稀释到 0.0x。实测一条 2:09 的视频，
一段 38 秒的录屏在阈值 0.3 和 0.2 下都一刀未切。调低全局阈值只会让别处切碎。

重新切分、补刀、合并都不会丢已有标注：标注按时间重叠迁移，重叠不足一半宁可空着也不张冠李戴。

### 标注

景别（10 档）· 运镜（12 种）· 构图（9 种，可多选）· 焦段（6 档）· 光线（12 种，可多选）·
机位（6 种）· 入点转场（7 种）· A-roll/B-roll 归类 · 复刻需求 · 元素 · 特效 · 逐镜备注。

全部做成固定选项而不是自由文本，这样能用快捷键点选，也能稳定地交给 AI。

### 键盘操作

| 键 | 作用 |
| --- | --- |
| `空格` | 播放 / 暂停 |
| `←` `→` | 上一个 / 下一个镜头 |
| `Enter` | 标记看完并跳下一个 |
| `S` | 在当前播放位置补一刀 |
| `M` | 并入上一个镜头 |
| `1`–`0` | 景别 |
| `Q`–`P` | 运镜 |
| `A` `;` `D`–`L` | 构图 |
| `Z` `X` `C` `V` | A-roll / B-roll / 叠加层 / 字卡 |

焦点在备注这类文本框里时，快捷键会暂停，播放按钮旁的提示会变成橙色提醒；按 `Esc` 退出输入。
快捷键按物理键位识别，开着中文输入法也能用。

### AI 初判：分 B-roll、找适合做模板的镜头（可选，要花钱）

每个镜头抽首、中、尾三帧送看图 AI（单帧看不出推拉摇移），判断：

- **归类**：A-roll / B-roll / 叠加层 / 字卡，不用再一个个手动分
- **适不适合做模板**：文字、图形、插画、图片动效这类代码画得出来的算适合，真人实拍不算。
  时间轴上带蓝色小方块的就是；右上角「…」里「只导出适合做模板的复刻包」一次导出它们，把里面的 clip.mp4 发给 Claude
- 景别、运镜、构图、光线、机位

AI 只填空位，你改过的（包括归类和适不适合做模板）下次再跑也不会被覆盖。
**准确率没有系统评测过，务必逐镜复核。**

```bash
export SHOTPILOT_VISION_API_KEY=sk-...
export SHOTPILOT_VISION_BASE_URL=https://api.openai.com/v1   # 可换成任意兼容网关或本地模型
export SHOTPILOT_VISION_MODEL=gpt-4o-mini
```

## 复刻：把参考镜头还原成可复用的代码

这是「复刻」而不是「生成」：输入是你看中的参考镜头，第一指标是**像**。

```bash
# 打包所有标为 B-roll / 叠加层 / 字卡的镜头（真人实拍复刻不了，只有这三类能用代码画出来）
pnpm replica --project <项目id> --all-broll --out ./replica-out

# 或只打一个镜头
pnpm replica --project <项目id> --shot s012
```

每个包里：

| 文件 | 作用 |
| --- | --- |
| `clip.mp4` | 原片这一段，不带音轨，**验收基准** |
| `frames/f0001.png …` | 逐帧序列（默认 10fps）。**动效分析必需**：单张关键帧看不出入场、移动、缩放 |
| `shot.json` | 画布尺寸、时长、画面标注、槽位定义 |
| `README.md` | 给 agent 的指令：摆位 → 动效 → 比对迭代，以及常见陷阱 |

把包丢进 Remotion 项目目录，在那里开 Claude Code / Codex，让它读 `README.md` 开工。
**不绑定任何 agent，就是一个文件夹。**

**复刻范围**：只复刻画面。口播字幕不复刻（后期加）；但画面设计里的文字（标题、字卡、文字框）属于画面，照常复刻。

### 比对：检查 AI 做得像不像

没有可测量的目标，AI 改完只能自己说「像了」，于是越改越飘。

```bash
pnpm compare --rendered out.mp4 --original clip.mp4 --diff diff.mp4
```

- 逐帧算 SSIM，指出**最不像的几帧**和对应的帧文件
- `--diff` 生成三联对比视频：**左 原片 · 中 复刻 · 右 差异**，差异图里黑=一致、亮=错位
- `--mask x,y,宽,高` 把某块区域排除在比对之外，最常用来遮掉原片里烧进去的口播字幕，
  例如 `--mask 0,610,1280,90`。可以写多个
- 退出码：0 通过 · 2 未达标 · 3 总分达标但有局部漂移

**局部漂移检测**：把画面切成 8×6 格，各自比较前 1/3 和后 1/3 的误差。某块越往后越不像，
说明原片那里有东西在缓慢运动，而复刻是静止的。这个问题看总分看不出来：实测案例里投影在旋转，
复刻做成了静止的，投影区误差从 0.55 涨到 13.4，可别的区域在变好，总分首尾反而是上升的。

> ⚠️ **总分达标不等于像。** 大面积平坦背景会把全幅 SSIM 撑高：实测案例在投影方向错误、
> 黑边也不对的时候，全幅 SSIM 就已经 0.976 了。**一定要看 `--diff` 的差异视频**，别只信数字。

### 在复刻的基础上加自己的想法

复刻做完就是一个模板：先保证和原片一模一样（比对工具验收），再把能改的地方做成「旋钮」。改的时候有两种方式：

- **在软件里直接改**：「用模板做视频」里右边是中文参数（换图、改文字、调时间和颜色），
  左边实时预览，改完一键导出。旋钮的默认值就是原片实测的数据
- **用一句话告诉 AI**：比如「气泡改成白底黑字」「拉远改成从左边滑进来」，让它改 `templates/src/` 里的组件代码

案例文件夹里的 `打开模板.command` 打开的是 Remotion Studio（英文界面，参数更全），做复刻验证时用。

这样你的改动是加在「已经测准的原片效果」上的，不是从零猜。

## 导出

| 格式 | 用途 |
| --- | --- |
| **拉片笔记（Markdown）** | 给人看：结构速览 + 逐镜拆解，可直接贴进笔记软件 |

## 已知限制

- **AI 初判的准确率没有评测过**。能跑通，但没调优，务必逐镜复核。
- **链接下载依赖本机的 yt-dlp**，能下哪些网站取决于它。抖音这类要求登录信息的平台，
  需要你先用 Chrome 打开过一次该链接，工具才能借到 cookie。
- **复刻只适用于代码画得出来的画面**：文字、图形、图片、转场、动效。真人实拍复刻不了，
  它在模板里是一个素材槽位，由你提供自己的素材。
- **Mac 软件没有苹果签名**，第一次打开要多点一次「打开」（见上面的安装步骤）。只支持 Apple 芯片。
- **软件自带的下载工具（yt-dlp）会慢慢过时**，抖音、B 站改版后可能下载失败，到时候更新一下软件。
- 导出视频用的是 [Remotion](https://www.remotion.dev)，个人和 3 人以内的团队免费使用。

## 开发

```bash
pnpm test
pnpm typecheck
pnpm build          # 打包界面（web/js/app.js）、模板（dist/remotion-bundle）、服务（dist/server）
```

加一个模板：在 `templates/src/` 下写组件和 `params.ts`（简单参数、中文表单描述、换算成组件参数），
在 `templates/src/registry.ts` 登记一行，界面和导出都会自动出现它。

Mac 软件由 `.github/workflows/mac-app.yml` 在 GitHub 的 Apple 芯片 Mac 上构建：
`desktop/stage.sh` 装进自带组件 → 打包 → 本机签名 → `desktop/smoke-test.sh` 冒烟测试（两个模板各导出一段、
切分一段测试视频）→ 发布到 `mac-latest`。
