# ShotPilot 拉片工作台

把别人视频里你喜欢的镜头，变成你自己能反复用的模板。

```
刷到一条喜欢的视频
   ↓  拉片：切成一个个镜头，标出哪些是 B-roll
挑出你喜欢的那个镜头
   ↓  导出复刻包，交给 AI
AI 把这个镜头做成 Remotion 代码模板
   ↓  换成你的头像、你的素材
得到你自己的视频片段，画面效果和原片一样
```

**只管画面。** 镜头怎么切、构图、景别、运镜、元素摆在哪、动效怎么走。
声音（背景音乐、人声）和口播字幕不归这个工具管，那些在后期里加。

## 为什么不是又一个剪辑软件

剪辑软件是为「产出成片」设计的，拉片是为「理解别人怎么拍」设计的，两者需求相反：

| 拉片真正需要的 | 剪辑软件的做法 |
| --- | --- |
| 一次性看到全部分镜 | 时间轴要来回拖 |
| 每个镜头挂结构化标注 | 只能改文件名或加马克点 |
| 标注能导出、能交给 AI | 锁在工程文件里 |
| 分镜边界可反复调整而不丢标注 | 重切等于重来 |

## 日常使用：不用敲命令

**双击 `ShotPilot.command`** 就能打开工作台（第一次双击后，桌面上会多一个同名快捷方式，以后从桌面双击）。
它会自动：尝试更新（连不上 GitHub 最多等 10 秒）→ 依赖有变化才重装 → 关掉没关的旧工作台 → 打开浏览器。
连不上 GitHub 时，它会自动使用「下载」文件夹里的更新包 `shotpilot-update.bundle`（AI 发给你的那个，不用双击打开，放着就行）。
用完直接关掉那个终端窗口。

在工作台里：

- **开始拉片**：首页输入框里**粘抖音 / B 站链接**（整段分享文案也行），自动下载后切分镜。
  抖音要求登录信息时，会自动借用 Chrome / Safari 的 cookie 重试。
  本地视频：在访达里选中文件，按 `Option + Command + C` 拷贝路径，粘到输入框
- **导出复刻包**：顶栏「导出复刻包」导出所有 B-roll / 叠加层 / 字卡；面板里「导出这个镜头的复刻包」只导出当前镜头。
  导出完自动在访达里打开文件夹

下载的视频在 `downloads/`，复刻包在 `replica-out/`。

## 第一次安装

需要用一次终端（之后就不用了）：

```bash
git clone https://github.com/miaoeliauk-sketch/shotpilot.git ~/shotpilot
cd ~/shotpilot && pnpm install
brew install yt-dlp        # 用来下载链接里的视频
```

然后在访达里打开 `~/shotpilot`，双击 `ShotPilot.command`。

## 命令行（可选）

也可以不开网页，直接走命令行：

```bash
pnpm analyze --input /path/to/ref.mp4 --threshold 0.3
pnpm analyze --project <项目id> --export md --out 笔记.md
```

## 拉片

### 切分镜：三层兜底

自动检测不可能百分之百准，所以分三层：

1. **全局自动切**：ffmpeg `scene` 滤镜 + 最短镜头合并，一进来就跑，解决大部分
2. **单镜头细切**：面板按钮「在此镜头内细切」，只对选中的镜头降低阈值重测
3. **手动补刀**：播到画面变了的地方按 `S`；切多了按 `M` 并回上一个

为什么需要后两层：同一条片子里不同内容的场景分数差一个数量级。真人画面人一动整帧都在变，分数很高；
录屏演示只有鼠标和局部界面在变，占整帧不到 5%，分数被稀释到 0.0x。实测一条 2:09 的视频，
一段 38 秒的录屏在阈值 0.3 和 0.2 下都一刀未切。调低全局阈值只会让别处切碎。

重新切分、补刀、合并都不会丢已有标注：标注按时间重叠迁移，重叠不足一半宁可空着也不张冠李戴。

### 标注

景别（10 档）· 运镜（12 种）· 构图（9 种，可多选）· 焦段（6 档）· 光线（12 种，可多选）·
机位（6 种）· 入点转场（7 种）· A-roll/B-roll 归类 · 复刻需求 · 元素 · 特效 · 逐镜备注。

全部做成固定选项而不是自由文本，这样能用快捷键点选，也能稳定地交给 AI。

### 键盘操作

| 键 | 作用 |
| --- | --- |
| `空格` | 播放 / 暂停 |
| `←` `→` | 上一个 / 下一个镜头 |
| `Enter` | 标记已审并跳下一个 |
| `S` | 在当前播放位置补一刀 |
| `M` | 并入上一个镜头 |
| `1`–`0` | 景别 |
| `Q`–`P` | 运镜 |
| `A` `;` `D`–`L` | 构图 |
| `Z` `X` `C` `V` | A-roll / B-roll / 叠加层 / 字卡 |

焦点在备注这类文本框里时，快捷键会暂停，底部提示条会变色提醒；按 `Esc` 退出输入。
快捷键按物理键位识别，开着中文输入法也能用。

### AI 初判景别和运镜（可选，要花钱）

每个镜头抽首、中、尾三帧送视觉模型（单帧看不出推拉摇移）。AI 只填空位，你改过的字段不会被覆盖。
**准确率没有系统评测过，务必逐镜复核。**

```bash
export SHOTPILOT_VISION_API_KEY=sk-...
export SHOTPILOT_VISION_BASE_URL=https://api.openai.com/v1   # 可换成任意兼容网关或本地模型
export SHOTPILOT_VISION_MODEL=gpt-4o-mini
```

## 复刻：把参考镜头还原成可复用的代码

这是「复刻」而不是「生成」：输入是你看中的参考镜头，第一指标是**像**。

```bash
# 打包所有标为 B-roll / 叠加层 / 字卡的镜头（真人实拍复刻不了，只有这三类能用代码画出来）
pnpm replica --project <项目id> --all-broll --out ./replica-out

# 或只打一个镜头
pnpm replica --project <项目id> --shot s012
```

每个包里：

| 文件 | 作用 |
| --- | --- |
| `clip.mp4` | 原片这一段，不带音轨，**验收基准** |
| `frames/f0001.png …` | 逐帧序列（默认 10fps）。**动效分析必需**：单张关键帧看不出入场、移动、缩放 |
| `shot.json` | 画布尺寸、时长、画面标注、槽位定义 |
| `README.md` | 给 agent 的指令：摆位 → 动效 → 比对迭代，以及常见陷阱 |

把包丢进 Remotion 项目目录，在那里开 Claude Code / Codex，让它读 `README.md` 开工。
**不绑定任何 agent，就是一个文件夹。**

**复刻范围**：只复刻画面。口播字幕不复刻（后期加）；但画面设计里的文字（标题、字卡、文字框）属于画面，照常复刻。

### 比对：检查 AI 做得像不像

没有可测量的目标，AI 改完只能自己说「像了」，于是越改越飘。

```bash
pnpm compare --rendered out.mp4 --original clip.mp4 --diff diff.mp4
```

- 逐帧算 SSIM，指出**最不像的几帧**和对应的帧文件
- `--diff` 生成三联对比视频：**左 原片 · 中 复刻 · 右 差异**，差异图里黑=一致、亮=错位
- `--mask x,y,宽,高` 把某块区域排除在比对之外，最常用来遮掉原片里烧进去的口播字幕，
  例如 `--mask 0,610,1280,90`。可以写多个
- 退出码：0 通过 · 2 未达标 · 3 总分达标但有局部漂移

**局部漂移检测**：把画面切成 8×6 格，各自比较前 1/3 和后 1/3 的误差。某块越往后越不像，
说明原片那里有东西在缓慢运动，而复刻是静止的。这个问题看总分看不出来：实测案例里投影在旋转，
复刻做成了静止的，投影区误差从 0.55 涨到 13.4，可别的区域在变好，总分首尾反而是上升的。

> ⚠️ **总分达标不等于像。** 大面积平坦背景会把全幅 SSIM 撑高：实测案例在投影方向错误、
> 黑边也不对的时候，全幅 SSIM 就已经 0.976 了。**一定要看 `--diff` 的差异视频**，别只信数字。

### 在复刻的基础上加自己的想法

复刻做完就是一个模板：先保证和原片一模一样（比对工具验收），再把能改的地方做成「旋钮」。改的时候有两种方式：

- **在预览页面里直接改**：双击案例文件夹里的 `打开模板.command`，浏览器右侧是所有参数（换图、改文字、
  调时间和颜色），改完画面立刻更新，并自动存回代码
- **用一句话告诉 AI**：比如「气泡改成白底黑字」「拉远改成从左边滑进来」，让它改组件代码

这样你的改动是加在「已经测准的原片效果」上的，不是从零猜。

## 导出

| 格式 | 用途 |
| --- | --- |
| **拉片笔记（Markdown）** | 给人看：结构速览 + 逐镜拆解，可直接贴进笔记软件 |

## 已知限制

- **AI 初判的准确率没有评测过**。能跑通，但没调优，务必逐镜复核。
- **链接下载依赖本机的 yt-dlp**，能下哪些网站取决于它。抖音这类要求登录信息的平台，
  需要你先用 Chrome 打开过一次该链接，工具才能借到 cookie。
- **复刻只适用于代码画得出来的画面**：文字、图形、图片、转场、动效。真人实拍复刻不了，
  它在模板里是一个素材槽位，由你提供自己的素材。
